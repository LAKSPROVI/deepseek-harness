# Agent Note: Router runtime evidence owns availability

Status: implemented

[English](2026-10-11-router-runtime-evidence.md) | 中文

## 问题

通过持久化 Settings 发布实时目录会使可用性依赖组件重新加载。整个周期共用的租约可能因本地查询延迟撤回仍然新鲜的模型，包括工具调用已完成之后。

## 决策

可选同步器发布独立于持久化 Settings 的 schema-2 运行时快照。每个准确模型 ID 保留原始检查时间和过期时间，最长十分钟。原生目录接收文件通知并每 30 秒兜底刷新；实际调用独立验证证据及投影后的工具。

网络、超时或服务端错误经过两次尝试后，仅保留未过期证据且不延长有效期。明确移除、否定证据、认证失败或格式错误会撤回选项。每个 ID 的检查和撤回水位在空快照后仍保留，防止旧响应恢复已撤回模型。

证据绑定 URL、协议、凭据引用和实际凭据值。预备调用保留此绑定。目录合并保留准确 ID 的选项和配置的容量上限。已知过期模型可请求一次续期，支持取消且最多等待 20 秒；已完成工具结果保留在历史中，不会重复执行工具或悄悄更换模型。

这部分取代[先前决策](../bug-fix/2026-10-07-router-live-catalog.zh.md)中的发布和周期租约策略。其限定配置读取及零模型路由契约仍有效。旧快照保留 60 秒确认期限。

## 考虑过的替代方案

**每个周期重新加载持久化 Settings。** 配置继承和组件加载增加与可用性无关的工作，并可能中断消费者。

**无限期保留旧列表。** 传输失败不会续期上游证据；过期和明确撤回仍必须执行。

**工具完成后更换模型。** 静默切换改变请求的执行，并可能重复外部动作。

## 影响

可用性独立于配置的模型元数据，不保证提供方未来持续运行。默认目录按实际工具投影筛选：路由 `gh/gpt*` 最多接受 128 个原生 schema。更大的投影会排除这些选项，但不会删除配置的工具。[使用说明](../../../../docs/user/router-live-catalog.zh.md)介绍同步与恢复。
