# 使用 Web UI

[English](index.md) | 中文

请先按照[根目录 README](../../../README.zh.md#run) 中的说明启动 Web UI；命令会打印其访问地址。本指南从服务器已经运行的状态开始。`dsh` 进程会把启动时所在的目录作为默认文件系统位置；全新的 Web UI 则不会选中任何工作区，你需要添加一个工作区。

## 配置模型

打开**设置 → 模型**，输入 [DeepSeek API 密钥](https://platform.deepseek.com/)并保存。模型路由会立即可用，不需要重启服务器。

[模型配置指南](./providers.zh.md)介绍其他提供方和自定义 OpenAI 兼容端点。

## 选择工作区

点击**选择工作区**，添加启动 `dsh` 时所在的项目目录，然后选中它。选中工作区前，会话输入框不可用。

## 运行任务

启动一个会话并发送：

> Summarize this repository and identify its main packages.

Agent（智能体）可以读取和编辑工作区文件、运行命令、委派工作并维护计划。如果根据当前权限策略，某项操作需要审批，Web UI 会先询问你。

## 重用已保存的提示词

打开**设置 → 提示词库**，即可创建、编辑或删除可重用提示词。在会话中，打开输入框旁的提示词库按钮，并按标题或正文搜索。选择提示词只会把内容插入草稿，绝不会自动发送；如果草稿已有文字，保存的正文会在一个空行后追加。

## 添加文件

使用**添加附件**、粘贴文件，或把文件拖到页面任意位置。PNG、JPEG、WebP 和 GIF 使用图片预览；包括 SVG、PDF、HTML 和压缩包在内的其他类型始终显示为惰性文件卡片。默认部署每次提交最多接受 20 个通用文件，单文件不超过 1 GiB，总量不超过 1 GiB。Harness 按精确的不透明字节存储文件，并强制下载历史文件，而不会在页面内渲染。

附件上限只表示传输与存储能力，并不保证所选模型能够理解该文件格式。不支持通用文件输入的路由会收到确定性的元数据说明，而不是文件字节。提交前移除草稿会把它从输入框丢弃；选择提示词或添加文件本身都不会发送消息。
